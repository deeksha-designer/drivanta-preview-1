# Drivanta Auto — Homepage Preview

Responsive single-page automotive B2B website preview with a local video hero, product-led sections, image-backed mega navigation, application tabs, and RFQ handoff.

All product, capability, certification, company, and contact information remains subject to client verification before publication.

Open `index.html` directly, or run `node preview-server.mjs` and visit `http://127.0.0.1:4173`.
